---
title: Open-source software
description: Overview of the open-source software BuilderNet is based on.
---

BuilderNet's block builder is derived from [rbuilder](https://github.com/flashbots/rbuilder). Production runs a Flashbots-maintained version with additional components, including bidding and orderflow ingress, which are not open source.

---

### Core services

| ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| [github.com/flashbots/rbuilder](https://github.com/flashbots/rbuilder)                                     | The open source block builder BuilderNet is derived from         |
